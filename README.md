¿Qué es una página web?

Una página web es un espacio que podemos visitar por Internet donde encontramos información, imágenes, textos, videos y otros contenidos.

¿Qué es HTML?

HTML es el lenguaje que utilizaremos para crear y organizar los elementos de nuestra página.

Por ejemplo:

El título.
Los textos.
Las imágenes.
Los párrafos.

Se puede explicar a los niños de la siguiente manera:

HTML es como el esqueleto de nuestra página web.

¿Qué es CSS?

CSS nos permite decorar y cambiar la apariencia de nuestra página.

Con CSS podemos cambiar:

Colores.
Tamaños.
Tipos de letra.
Fondos.
Espacios.
Posición de algunos elementos.
